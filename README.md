# 🛠️ **ToolBox** - Mi proyecto full stack 🛒

Bienvenido a **ToolBox**, un proyecto demo de una página web que te ofrece una variedad de productos de ferretería.

## 🎉 **Características Principales:**

- **Roles de Usuario:**  
  - **User**: Acceso básico a la compra de productos.  
  - **Admin**: Puede ver, editar y agregar productos y gestionar compras.
  - **Boss**: Acceso completo a todas las funcionalidades de gestión.

- **Autenticación de Usuarios:**  
  - **Registro**: Crea una nueva cuenta.  
  - **Inicio de Sesión**: Accede a tu cuenta.  

- **Gestión de Inventario:**  
  - Agrega, elimina y edita productos.  
  - Descarga el inventario en formato PDF.  

- **Métodos de Pago:**  
  - Confirma tus compras y selecciona entre varios métodos de pago.  
  - Recibe un correo electrónico con un resumen de tu compra y los productos adquiridos.  

- **Atención al Cliente:**  
  - Accede a las redes sociales de la página.  
  - Consulta sobre los métodos de pago disponibles.

## 🛠️ **Herramientas y Tecnologías Utilizadas:**

Este proyecto fue desarrollado utilizando las siguientes herramientas y tecnologías:

- **Node.js**: Entorno de ejecución para JavaScript en el lado del servidor.
- **Express**: Framework web para crear aplicaciones y APIs.
- **MongoDB**: Base de datos NoSQL utilizada para almacenar datos de usuarios, productos y compras.
- **Mongoose**: ODM (Object Data Modeling) para MongoDB, que simplifica el trabajo con la base de datos.
- **EJS**: Motor de plantillas para generar HTML dinámicamente.
- **Bcrypt.js**: Biblioteca para encriptar contraseñas de usuarios.
- **Nodemailer**: Módulo para enviar correos electrónicos desde la aplicación.
- **PDFKit**: Biblioteca para generar documentos PDF de manera programática.
- **ExcelJS**: Herramienta para trabajar con hojas de cálculo de Excel.
- **Multer**: Middleware para manejar la subida de archivos.
- **Axios**: Cliente HTTP para hacer solicitudes a servicios externos.
- **Cookie-Parser**: Middleware para analizar cookies en las solicitudes HTTP.
- **Express-Session**: Middleware para manejar sesiones de usuario.
- **Connect-Mongo**: Almacenamiento de sesiones en MongoDB.
- **Form-Data**: Biblioteca para manejar formularios con datos multipart.
- **Bunny Storage**: Servicio de almacenamiento utilizado para guardar imágenes de productos (prueba gratuita).

Estos componentes han sido esenciales para construir la funcionalidad y la estructura de **ToolBox**. ¡Gracias por tu interés en conocer más sobre nuestro proyecto! 💻✨
